# 필드 공략 플레이북 (DSR)

보스는 따로 — [../boss/README.md](../boss/README.md).
필드 = 여러 마리·지형·길 찾기. 목표는 **다음 화톳불·목적지까지 살아서 가는 것**이지 다 잡는 게 아니다.
(엘든링 쪽 웹 조사 후보는 [../playbook-notes.md](../playbook-notes.md).)

## 0. 지금 계획 (2026-09-24 수정)

- **묘지(츠바이헨더 시체 쪽) 해골 길은 가지 않는다** — 사용자가 직접 싸워 봄: 레벨 차이가 커서 상대가 안 된다. 아래 해골 표·실측은 나중(레벨 올린 뒤)용으로만 남긴다.
- **츠바이헨더는 얻었지만 근력(STR) 16 미만이라 못 쓴다** — 레벨업 전엔 브로드소드.
- **다음 목표: 망자 상인 쪽 성벽 마을 화톳불 찍기** (불 붙이고 앉아 귀환 지점으로):
  ```bash
  BOT_GAME=dsr .venv/Scripts/python.exe hunt.py --merchant --light-burg
  ```
  불의 제전 → 계단 → 다리 → 성벽 마을 → 상인 → 화톳불(3.2, -10.0, -61.2) → A(불 붙이기) → A(앉기) → 마지막 화톳불 ID 확인 → B.

## 1. 원칙

- **길은 사람이 가르친다** — 사용자가 직접 걸으며 녹화(`record_play.py`), 갈림길마다 위치+스크린샷 → 그 경로를 따라간다. 스크린샷 체크포인트 비교로 멈춤 감지(`stall_watch.py`).
- **락온 안 씀** — 메모리 heading 으로 몸을 맞춘다 (락온이 피해의 절반 원인이었다).
- **대부분 가드, 필요할 때만 공격, 둘러싸이면 도망.** 가까운 한 마리는 먼저 잡는다 (방패 들고 다가가 R1 — `boss/ah.py`).
- **R1·B 전엔 스틱을 놓고 0.16 s** (안 그러면 발차기). 후진은 백스텝, 백스텝+약공도 좋은 공격.
- **방패 병사가 막으면 발로 차고** 곧장 공격.
- **떨어지거나 둘러싸이면 Quit Game** (다크사인 쓰지 않음 — 소울·인간성 손실). 원위치로 돌아간 적은 정리.
- 죽으면 핏자국 회수 (`hunt.BloodWatch`).
- 안내창("A: …")은 보는 즉시 끈다. 이벤트 트리거는 MSB regions 이름으로 찾는다 (예: 쇠공 굴리기).
- 사다리: 사다리 쪽으로 **몸을 돌려야** 안내가 뜬다 → A → 스틱 위/아래.

읽는 법:
- 해골은 공격마다 **스텝인(700)으로 거리를 한 번에 좁힌다** → 달려서 지나가도 뒤에서 잡힌다 (츠바이헨더 1차 사망). 멀리선 구르기로 피하기도 해 맞추기 어렵다.
- 해골 3연타(3000→3002)는 가까울수록 잦다 → 막으면 스태미나가 바닥난다 (한 대 ~170, 2차 사망). 한 번에 둘 이상 받지 말 것.
- 망자 둘은 가까이 가면 **거의 반은 단발(3008)** 이고 나머지가 2~3타 콤보 — 단발을 막고 바로 1대, 콤보면 끝까지 막고 1대.
- 방패 병사는 **가드만 올리고 있으면 가드 브레이크로 깨러 온다** → 막기만 하지 말고 옆으로 돌거나 발차기(사용자 팁)로 먼저 깨라.

## 2. 자원

- 화톳불에서 에스트 채움, 자주 가는 화톳불은 불 지피기(인간성 1 → +5).
- 에스트 아이템 번호는 강화 단계별(200~215) — 새 캐릭터 201.
