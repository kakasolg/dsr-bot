## 1. 한 줄 요약

**정면 싸움은 하지 않는다.** 망루(사다리 위)에서 떨어지며 치는 낙하 공격만 되풀이한다:
황금 송진 → 다리에서 불러냄 → 사다리로 달려 올라감 → 밑에 오면 낙하 공격 → 약공 1번 → 다시 사다리 → 낙하 … 2~3번이면 잡힌다.

### 2-1. 성공한 순서와 책임 · 진입 검사 (2026-10-31)

10-12에 보스까지 가서 잡은 두 번은 모두 **명령 두 개**였다: `run.py burg-upper --seg 1-8` → `run.py taurus`
(`004844`→`005650` 코드 `9763a4b`, `024340`→`025057` 코드 `6341df3`). 시작 상태: 마을 화톳불, SL 18 캐릭터, 퀵슬롯
`[205, 311, …]`(송진 3). 시작 세이브 이름은 기록에 없다. 세이브 포인트 `backup-20261011-235526-zone8-top-taurus-start`는
석궁병 죽음·송진 3인 상태.

|---|---|

| 탑 위 석궁병 둘 | `burg-upper` 구역 8 (`data/burg-upper-map.json`: 안개벽 → 사다리 → 구르기 → 255002 둘) |
| 송진 바르기 · 보스전 | `run.py taurus` = `souls/taurus.py` (`_resin`은 바른 뒤 개수가 줄었는지 확인) |
| 다리 건너 제단 | `run.py burg-altar` — **타우로스를 이미 잡은 캐릭터용** (구역 1~7 → 안개벽 → 다리, 구역 8 안 함) |

10-31 `155929_burg-altar`는 타우로스가 살아 있는 캐릭터(불의 제전 도착 세이브 e2da9f35 계열, SL 7, 퀵슬롯에 311 없음)에
burg-altar를 써서 석궁병·송진 없이 다리로 갔고 보스에게 죽었다. 그래서 두 명령 앞에 진입 검사(`boss_ready.py`)를 둔다 —
**미충족이거나 확인할 수 없으면 이동·공격·아이템 사용 전에 멈추고 이유를 로그·`ready` 사건에 남긴다.** 자동으로 다른 경로로
넘어가지 않는다.

- `burg-altar`: 타우로스 처치가 확인돼야 감 (같은 보스가 스냅숏 두 번 연속 HP 0, 또는 처치 기록). 살아 있으면
  "먼저 burg-upper --seg 1-8 → taurus", 안 보이면 "확인 불가". **처치 기록(이벤트 플래그) 번호는 아직 모른다** → 같은 세션에서
  HP 0으로 보일 때만 감. 다른 세션·재접속 뒤 잡은 보스가 보이는지는 미측정 (그때 못 보면 멈춤).
- `taurus` (안개벽 앞): 석궁병 둘이 탑 위에서 HP 0으로 보일 것(살아 있음 → 구역 8 먼저, 안 보임 → 확인 불가) · 황금 송진
  ≥ 1 **그리고** 퀵슬롯에 있음 (이 경로는 송진 필수, 자동 장착 안 함) · 에스트 ≥ 1. 상자 기록(51010460)·문 상태는 기록만
  (문 기록 번호는 모름 → "확인 불가"). 상자 기록이 있는데 송진 0이면 "다 씀".
- 읽기 실패는 0개·처치로 바꾸지 않고 "확인 불가"로 멈춘다.
- **과거 기록(위 성공 실행, 세이브 포인트 설명)은 지금 세이브 상태의 증거가 아니다.** 새 실행마다 지금 읽은 값으로만 판단한다.

- 꼭대기에서 떨어져 버리면 기다리지 말고 바로 8번으로.
