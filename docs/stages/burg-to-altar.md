## 3. 클레이모어로 바꿀 때 (무기 점검, 2026-10-12)

`souls/weapons.py` `Weapon` 필드로 무기별 동작이 갈리게 되어 있어서 **대부분은 무기만 바꾸면 따라옴**:
- 벽 강공 · 잠든 적 첫 강공 · 방패병 양손 콤보 = `heavy_vertical` 무기만 → 클레이모어는 꺼짐
- 끊어 치기(`rule_hit_first`) = 준비 ≤ `INTERRUPT_STARTUP_MAX` 0.45 s → 클레이모어(0.68 s)는 꺼짐 (09-25 254010 피해 때문)
- 약공 타이밍(연타 · 가드 복귀)은 startup / active / recovery / chain_gap에서 계산

모자란 것:
- **측정값이 낡음**: 클레이모어 reach 1.8은 위키값(실측 전), 헛스윙 측정은 09-25(옛 캐릭터 STR 16 한손). chain_gap은 기본값 0.2.
  배틀 액스처럼 `experiments/swing_probe.py`(약공·강공 찌르기)와 블랙박스 거리별 명중(`experiments/knife_hits.py 253000 253999`)으로 다시 잼.
- **잡는 법**: 한손 STR 16 / 양손 11. 지금 캐릭터 STR은 기록 없음 → 게임에서 확인. 한손이면 방패 유지(지금 규칙 그대로),
  양손이면 방패가 없어져 가드 · 반사 규칙 전체가 달라짐 → [MoKa] 결정.
- **가로 베기가 벽에 걸림**: 배틀 액스는 벽 앞에서 수직 강공으로 피했는데, 클레이모어는 약공이 가로라 좁은 곳에서 더 불리할 수 있음.
  강공(찌르기)을 벽 앞에서 쓸지는 측정 뒤.
- **시험이 배틀 액스 기준**: `duel_golden_test` 세 번째 묶음 · `duel_expect_test` 장면 · sleeper / wall-heavy 테스트가 모두 BATTLE_AXE.
  클레이모어 묶음을 추가해 같은 장면에서 규칙이 어떻게 갈리는지 본다.
- `weapons.DEFAULT`(모르는 무기 ID) = 배틀 액스 — 클레이모어가 주무기가 되면 바꿀지 [MoKa].
