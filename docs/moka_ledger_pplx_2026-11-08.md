# Perplexity checks 2026-11-08
- Q1 backstab/riposte i-frames (M1108-11): AGREES. wiki: attacker+victim invincible during backstab anim; IGN same for riposte; exception DoT (poison/toxic/Power Within). Failed BS in DS1 = plain R1 (no whiff anim), no i-frames -> open. Sources: darksouls.fandom, IGN, steamcommunity guide.
- Q2 Battle Axe directions (M1108-14, M0928-02, P-139): AGREES with MoKa correction. 1h R1 horizontal R->L; 1h R2 vertical overhead; 2h R1 horizontal; 2h R2 overhead; rolling R1 fast overhead chop. Rule is clearance: horizontal catches side walls. Sources darksouls.fandom, wikidot.
- Q3 stamina while guarding (M1108-16, M1103-13, M1012-03): AGREES with MoKa's worry. fextralife: base 45 SP/s, guard raised ~80% slower (~9/s) even when not hit. Blocking also costs SP; 0 SP -> guard break. 2h weapon block lets damage through (Claymore 2h 60% phys, Zweihander 70%); shields 100% phys. Advice: drop guard in safe gaps. Taurus 2h guard approach "viable but poor trade" per answer (opinion, not sourced fact).
- Q4 groups (M1108-08/09/10, M0930-01, M0924-04, M1001-07, M1108-04): AGREES mostly. Arqade (gaming.stackexchange): pull one at a time, retreat and draw out individually = usual best; "hit the same enemy with every attack" (finish damaged first) — answer adds: preference, not at any cost (defend/reposition if another can hit you). Chokepoints/stairs help by geometry; but narrow spaces make wide swings hit walls -> use thrust/vertical (vgkami). Turn-taking: NOT reliable — hollows can overlap and stunlock (fextralife hollow page, steam guide). Wall hit noise: community-reported "hitting walls might also alert nearby enemies" (steam guide, reddit), no exact radius.
  -> MoKa "적이 자동으로 순환" : sources say rotating in front is possible but don't rely on turns; overlap happens.
- Q5 Taurus (M1102-01, M1103-21/22/23/24, M1012-09, M1108-16): MIXED. fextralife: plunges repeatable (no limit, ~2-4 needed), reset by leading him to far end, dodge past, climb — not "climb again immediately" (he hits you on ladder; can jump onto roof). MoKa = one plunge then bridge melee (risk choice, guides allow either). Close range: swings can pass overhead (player reports), but ground stab + feet still hit — positioning advantage, not safe. Attack after overhead smash lands, from behind; one light conservative default, second only with time+SP (answer's synthesis). Lower shield between threats for SP (agrees with Q3). Resin "substantially stronger".

- Q7 techniques:
  (1) shield bounce -> immediate R1 (M1108-01, M1104-01): AGREES, IGN recommends block-and-retaliate vs hollow soldiers; start with one hit. Bounce comes from hidden "deflection" tier (small light/normal medium/great heavy), NOT stability; stability = SP cost. (related link title mentions +40% damage on bounced enemies — not checked)
  (2) kick vs Burg spear/shield soldiers (M0925-09, M1103-04, M0000-09): AGREES, kick raised shield then R1 immediately (reddit); fresh forward tap + R1; alt: bait thrust, block, punish recoil. Kick only while shield up, not during thrust.
  (3) forward+R2 jump attack guard break (M1103-11): PARTIAL — can open shields (axe vs spear hollows, reddit) but not universal; jump attacks are unparryable, not unblockable.
  (4) rolling vs backstep (M1103-02/03/20, M0924-02): roll→R1 to punish after evading; backstep→R1 to make attack fall short then re-enter. Answer says rolling attacks not inherently bad vs same-size fast foes — depends where the roll ends / follow-ups ("roll, reassess, then attack"). MoKa's M1103-20 (hard on same size) = experience; sources neither confirm nor refute strongly.
  (5) lock-on for heavy/combos (M1012-01, M1103-10): mostly agrees for 1v1 duel; locked rolls only 4 directions; unlock to reposition.
  (6) two-hand only clear 1v1 (M1001-01): conservative learning rule, not mechanical; 2h = 1.5x STR, lose shield.
  (7) sleeping/idle opener heavy (M1003-03, code only): DIFFERS — prefer backstab if eligible and back reachable (wikidot); R2 if not.
  (8) backstab fails near walls (M0928-05): NOT a verified rule; requirements = rear position, level elevation, eligible enemy, shield lowered; cramped space makes positioning harder.
- Q8 Burg/Asylum:
  (1) Hellkite (M1012-11/12/13, M1013-01): AGREES. wikidot: wait in sheltered midpoint corner ~20-30 s -> it lands; before ladder shortcut kicked it won't leave perch unless attacked; sprint past into doorway, rest at bonfire. Shortcut ladder kick; under-bridge route.
  (2) firebomb hollows (M0926-04, M1102-04): rush isolated bomber; if supported, lure melee first; knives OK with clear shot (not guaranteed kill).
  (3) crossbow (M1011-01 no kick, M1103-06 roll-in, M1101-07): no-kick AGREES (kick is for raised shields). Approach: block bolts or evade once, advance in reload gap — "roll repeatedly not necessary" (partial vs M1103-06). Tower crossbowman before Taurus: attack legs from stairs below.
  (4) Asylum Demon (M0929-02/03): AGREES — stay close, circle behind, short attacks; blocking viable backup except long overhead + butt slam -> move away.
  (5) barrels/crates roll-break (M0000-08): AGREES (eurogamer).
  (6) hit first -> hollow backs off (M0000-03): PARTIAL — poise-based flinch, not guaranteed; stepping back is not proof of a window. Asylum Demon immune to normal stagger.

  (1) plunge off stairs/ledge onto normal enemies (M1108-13): works on normal enemies (wikidot: Butcher, boar); R1 while falling; no fixed min height; Havel: "a few steps higher than his head". Walking down stairs is not a plunge. forward+R2 toward lower enemy is a separate move, works if reach connects.
  (2) heavy-centric = advanced (M1108-15): DIFFERS in framing — R2-centric viable but not a marker of skill; agrees it is harder (startup, recovery, SP, spacing) so it does test timing.
