# 보스 공략 플레이북 (DSR)

필드와 보스는 방법이 다르다 — 필드는 [../field/README.md](../field/README.md).
필드 = 여러 마리·지형·길 찾기, "멈추지 말고 지나가거나 하나씩". 보스 = 한 마리·정해진 방·**고정된 AI 표**를 읽고 대본대로.

## 1. 공략 순서 (새 보스마다 이대로)

1. **AI 표를 먼저 읽는다** — 적 패턴은 Lua 다.
   `DARK SOULS REMASTERED\script\<맵>.luabnd.dcx` → zlib → BND3 → `<npc id>_battle.lua` (Lua 5.0 바이트코드 `\x1bLuaP`).
   ```bash
   python boss/luadump.py 223200_battle.luac dis > 223200_dis.txt
   ```
   `*_Activate` 함수에 **거리 구간별 공격 확률표** (`GetDist` 비교 → `SETTABLE actPerArr`), `IsInsideObserve` 로 **몸 옆·뒤 감시 구역** 반응이 있다.
   `Act01..` 함수 순서가 공격 애니 번호(3000…)와 대응 — 각 Act 함수 상수에 애니 번호가 보인다.
   → 결론: 어느 거리·방향이 안전한지(표가 약한 곳)를 먼저 안다.
2. **애니 타이밍 실측** — 텔레메트리로 애니 시작 → 내 HP 깎인 시각 (HIT_AT), 애니 길이 (DUR), 닿는 거리.
   맞은 때는 전부 기록: (보스 애니, 나이, 거리, 보스 정면 기준 각도, 내 모드). "맞았으면 앞쪽에 있었던 것"(사용자).
3. **입장 전 준비** — HP·에스트 꽉 채우고 들어간다. 무기 양손(Y) — 낙공·약공 피해가 오른다.
4. **대본** (수용소 데몬에서 이긴 틀, 사용자가 본 고수 플레이):
   - 가능하면 **낙하 공격**으로 시작 (보스가 나를 보게 한 뒤 떨어지며 RB 연타).
   - **가드·구르기 안 함** — 스태미나를 공격에만 쓴다. 가드는 회복을 늦추고 구르기는 스태미나를 먹는다.
   - **등 뒤(엉덩이·꼬리)에 붙어 약공 1대씩.** 1대 = 짧아서 반격 틈이 없다.
   - 앞쪽(보스 정면 기준 < 100°)이면 **몸을 뚫고 가지 말고 크게(3.8 m) 돌아** 등 쪽으로, 100° 넘으면 붙는다.
   - **범위기(점프 엉덩방아 등)는 밖으로 달려서** 피한다 — 닿는 시각까지 반경 밖.
   - **전투 중 에스트 안 마신다** (사용자: 마시는 것도 리스크). 마셔야 할 만큼 맞는다면 대본이 틀린 것 → 로그로 고친다.
5. **데이터로 복기** — `boss_dist.py` 로 거리·모드별 맞은 피해/분, 준 피해/분. 스크린샷 1 s.

## 2. 하지 말 것 (실측으로 실패한 것)

| 시도 | 결과 |
|---|---|
| 거리 두고(4~7 m) 돌기 | 데몬 AI 가 그 거리에서 2타 콤보 90% → 두 번째 타격에 계속 맞음 |
| 가만히 서서 보기 | 닿는 거리 7.8 m, 멈추면 무조건 맞음 ("멈추면 죽는 거야") |
| 공격 직전 구르기 회피 | i-frame 은 되지만 스태미나 바닥, 콤보 두 번째에 맞음, 공격 기회 없음 |
| 굴러 들어가 약공 (4.6 m 이상) | 거의 헛침 |
| 90° 돌기만 하고 정면에서 들어가기 | 들어가는 순간 각 0° — 맞거나 헛침 |
| 등 뒤 점으로 직진 | 보스 정면에 몸이 걸려 2 m 에서 멈춤 → 즉사 (첫 시도 24 s) |
| HP 75% 에서 에스트 | 초반에 다 씀, 마시다 맞음 |

## 3. 보스 카드

### 수용소 데몬 (Asylum Demon, npc 223200, HP 813) — 처치 2026-09-24, 102 s

- 입장: 화톳불 2 → `boss/fog.py` → 안개 A → 발판 끝에서 데몬이 나를 보면(3020/3021) 달려 떨어지며 RB.
- 낙공(양손) 318, 약공(양손 브로드소드) 38.
- AI 표 (`223200_battle.lua`):

| 내 거리 | 데몬 선택 |
|---|---|
| ≥ 11.5 m | 3007 70% |
| 7–11.5 m | 3000 · 3001 각 35%, 3002 · 3003 각 15% |
| 4.2–7 m | **3002→3011/3012 콤보 45%, 3003→3013 콤보 45%**, 3006 10% |
| 1.5–4.2 m | 3006 50%, 3002 · 3003 각 20% |
| < 1.5 m | 3006 45%, **3008 점프 엉덩방아 45%** |
| 몸 옆 감시 구 (더미 3 r2 / 4 r3) | 회전 3004/3005 85% |

- 타격 시각(애니 시작부터, s): 3000 1.77 · 3002 1.26 · 3003 1.6(+3013 ~2.0) · 3005 1.46 · 3006 1.72(+2.14) · 3008 **4.05 범위** · 3010 2.63 · 3011 1.15 · 3012 1.8(+2.23) · 3013 1.9.
- 이긴 대본: 엉덩이 쪽 각 120~176°, 거리 2.1~3.2 m 에서 약공 1대 → 약 2 s 간격. 3대쯤 치면 3008 → 8.4 m 밖으로 달림 (4 번 모두 피해 0). 맞은 7 번은 전부 앞쪽을 돌아가던 중.
- 기록: `data/trace/boss_*.json` (fine 행 = t, 내 hp, sp, 내 애니, 데몬 hp, 데몬 애니, 거리, dy, 각, R, 모드, 내 x z, 데몬 x z, heading).

## 4. 파일

| 파일 | 하는 일 |
|---|---|
| `fog.py` | 화톳불 2 → 보스 안개 앞 (가는 길 할로우 처리) |
| `boss.py` | 낙공 + `butt_fight()` (위 대본). `fight()` 는 옛 거리 실험용 |
| `ah.py` | 수용소 이동·전투 도우미 |
| `luadump.py` | Lua 5.0 바이트코드 상수·디스어셈블 |
| `boss_dist.py` | 거리·모드별 피해 집계 |

```bash
BOT_GAME=dsr .venv/Scripts/python.exe boss/fog.py && BOT_GAME=dsr .venv/Scripts/python.exe boss/boss.py
```
